notepadcc 1.0.0 发布说明

概览

notepadcc 是原生 Windows x64 文本 / 源码编辑器，内核嵌入 Scintilla + Lexilla，
外壳使用 Win32 与 C++20，不依赖 .NET、Qt 或 Electron。项目按 GNU GPL v3.0 only
发布，官方发行免费。1.0.0 以源代码形式发布，GitHub Release 不提供预编译二进制。

亮点

多标签、会话恢复、查找替换、在文件中查找 / 替换、列编辑与超大文件映射视口。
语法着色、UDL、样式方案、暗色与护眼模式；自绘菜单栏、工具栏、标签栏、状态栏和
业务对话框共用一套现代 chrome，支持浅色 / 深色 / 护眼四组配色。
窗口、任务栏、资源管理器和安装快捷方式统一使用作者徽标制作的多尺寸透明图标。
文件比较、JSON / XML 树视图、XPath、Markdown 预览、十六进制查看与脚本插件。
FTP / SFTP 远程编辑、宏、运行命令、插件宿主与工具栏 / 右键菜单定制。
更新包同时校验清单签名、SHA-256 与 Authenticode，任一失败即拒收。
主窗口状态栏显示作者标识，悬停或单击可查看完整作者与联系信息。

构建

本版本不提供预编译二进制。请克隆仓库，按 README 安装 CMake 与 MSVC 或 MinGW，
运行 scripts\fetch_deps.ps1 获取第三方源码，再使用 CMake 构建 Windows x64 程序。

系统要求：Windows 10 1809 或更高，x64。建议使用静态运行库构建，以便生成无需另装
VC++ 可再发行组件的绿色便携版。

校验

本 Release 仅提供源代码与发布元数据，因此不包含 EXE、MSI 或绿色包的 Authenticode
签名。下载后请核对源码包与 SHA256SUMS 中的 SHA-256。自行构建并对外分发二进制时，
签名与 SmartScreen 提示由分发者自行负责。

已知边界

自绘控件尚未接入屏幕阅读器 / UIA、高对比模式与输入法候选窗。
系统 MessageBox 与系统文件 / 颜色选择器仍由 Windows 绘制。
本轮性能与兼容实测在 Windows 11 build 26200、系统 DPI 192 上完成。
